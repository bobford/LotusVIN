# LotusVIN
Corrects a corrupted VIN for a 2005, 2006, or 2007 Federal Elise.

This app is used to program the VIN on a Lotus Elise, 2005, 2006, or 2007 model year.
The user should enter a five digit number, the last five digits of the desired VIN. The
check digit will be computed automatically.
An ELM327 Bluetooth interface should be plugged into the OBD-II port and paired with the Android phone. The first time the app is run, it may ask for permission. On later tries, it will display the available Bluetooth devices fro the phone. Select the ELM327 in use.
Then enter the five digit number from the low digits of the correct VIN.
This app targets SDK 36.
